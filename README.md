# IPL Data Analysis – Capstone Project

## Project Overview

This project focuses on Exploratory Data Analysis (EDA) of Indian Premier League (IPL) match data using Python. The objective is to analyze match statistics, identify trends, understand team and player performances, and extract meaningful insights from historical IPL data.

The analysis uses Python libraries such as Pandas, NumPy, Matplotlib, and Seaborn for data cleaning, manipulation, statistical analysis, and visualization.

## Project Objectives

- Analyze IPL match results and team performances.
- Examine the relationship between toss decisions and match outcomes.
- Identify top-performing teams and players.
- Explore highest individual scores and best bowling figures.
- Analyze batting and bowling performance trends.
- Present findings through meaningful visualizations.

## Dataset Description

The dataset contains IPL match-level information, including:

- Match ID and date
- Venue and participating teams
- Toss winner and toss decision
- First and second innings scores
- Match winner and victory margin
- Player of the Match
- Top scorer and highest score
- Best bowling performance

## Analysis Performed

### 1. Data Exploration and Cleaning
- Examined dataset dimensions and structure.
- Checked column names and data types.
- Identified missing values and duplicate records.

### 2. Team Performance Analysis
- Analyzed match-winning teams.
- Compared team performances.
- Examined match results and victory margins.

### 3. Toss Analysis
- Analyzed toss winners and match winners.
- Examined batting and fielding decisions.
- Calculated the percentage of matches won by toss winners.

### 4. Batting Analysis
- Identified top run-scorers.
- Explored highest individual scores.
- Analyzed batting performance patterns.

### 5. Bowling Analysis
- Identified the top 10 best bowling figures.
- Compared bowling performances.
- Explored wickets and runs conceded.

## How to Run the Project

1. Clone this repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd IPL-Data-Analysis
   ```

3. Install the required libraries:

   ```bash
   pip install pandas numpy matplotlib seaborn
   ```

4. Open the notebook using Jupyter Notebook or upload it to Google Colab.

5. Update the dataset path if required and execute the notebook cells.
